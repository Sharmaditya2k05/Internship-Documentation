# Introduction

Machine Learning models are generally trained in notebooks or Python scripts. However, for real-world applications, these models must be deployed so that other applications can access their predictions.

Flask is a lightweight Python web framework that enables machine learning models to be deployed as RESTful APIs. In this project, a Random Forest classifier was trained using the Iris dataset and integrated into a Flask application. The API accepts flower measurements from users and predicts the corresponding Iris species.

# Code Implementation

## Model Training

```python
import pickle

from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier

iris = load_iris()

X = iris.data
y = iris.target

model = RandomForestClassifier(
    random_state=42
)

model.fit(X, y)

pickle.dump(
    model,
    open("model.pkl", "wb")
)
```

---

## Flask Application

```python
from flask import Flask
from flask import request
from flask import jsonify

import pickle
import numpy as np

app = Flask(__name__)

model = pickle.load(
    open("model.pkl", "rb")
)
```

---

## Home Route

```python
@app.route("/")
def home():

    return "Iris Prediction API is Running"
```

---

## Prediction Endpoint

```python
@app.route("/predict", methods=["POST"])

def predict():

    data = request.get_json()

    features = np.array([

        data["sepal_length"],
        data["sepal_width"],
        data["petal_length"],
        data["petal_width"]

    ]).reshape(1,-1)

    prediction = model.predict(features)

    return jsonify({

        "prediction": int(prediction[0])

    })
```

---

## Run Flask Server

```python
if __name__ == "__main__":

    app.run(debug=True)
```
