# 1. Introduction to Computer Vision

Computer Vision is a branch of Artificial Intelligence that enables machines to understand and interpret visual information from images and videos.

The goal is to make systems capable of performing tasks such as:

- Object Detection
- Face Recognition
- Image Classification
- Medical Image Analysis
- Autonomous Driving
- OCR (Optical Character Recognition)

CNNs are one of the most important technologies powering modern computer vision systems.

---

# 2. What is Image Classification?

Image Classification is the process of assigning a label or category to an image.

Example:

| Input Image | Predicted Class |
|---|---|
| Cat Image | Cat |
| Dog Image | Dog |
| Car Image | Car |

The model learns visual patterns from training images and predicts the correct category for unseen images.

---

# 3. Traditional Machine Learning vs CNNs

## Traditional ML Approach

Traditional methods required manual feature extraction.

Steps:

1. Extract features manually
2. Feed features into ML model
3. Predict output

Problems:

- Time consuming
- Less accurate
- Human dependency
- Poor scalability

## CNN Approach

CNNs automatically learn features from images.

Advantages:

- Automatic feature extraction
- Better accuracy
- Learns complex patterns
- Works well on large datasets

---

# 4. Basics of Digital Images

An image is represented as a matrix of pixel values.

## Grayscale Image

Single channel.

Pixel range:

- 0 → Black
- 255 → White

Shape example:

28 × 28

## RGB Image

Contains 3 channels:

- Red
- Green
- Blue

Shape example:

224 × 224 × 3

---

# 5. Neural Networks Refresher

A Neural Network consists of:

- Input Layer
- Hidden Layers
- Output Layer

Each neuron performs:

1. Weighted sum
2. Activation function
3. Output generation

Traditional dense networks are not efficient for image data because:

- Huge number of parameters
- Loss of spatial information

CNNs solve these issues.

---

# 6. What is a Convolutional Neural Network (CNN)?

CNN is a deep learning architecture specifically designed for image processing.

Key idea:

Instead of connecting every neuron to all pixels, CNNs focus on local regions using filters.

CNNs learn:

- Edges
- Shapes
- Textures
- Patterns
- Objects

Automatically.

---

# 7. Core Building Blocks of CNNs

Main components:

1. Convolution Layer
2. Activation Function
3. Pooling Layer
4. Fully Connected Layer
5. Output Layer

---

# 8. Convolution Operation

Convolution is the most important operation in CNN.

A small matrix called a filter slides over the image.

At each position:

1. Element-wise multiplication
2. Summation
3. Output generation

This helps detect patterns.

Example features detected:

- Vertical edges
- Horizontal edges
- Corners
- Curves

---

# 9. Filters / Kernels

A filter is a small matrix such as:

3 × 3
5 × 5
7 × 7

Each filter detects a specific feature.

Examples:

| Filter Type | Detects |
|---|---|
| Edge Filter | Edges |
| Blur Filter | Smoothness |
| Sharpen Filter | Sharp details |

As training progresses, CNN learns the best filters automatically.

---

# 10. Feature Maps

The output produced after convolution is called a Feature Map.

Feature maps contain important extracted features from the image.

Early layers detect:

- Edges
- Lines

Middle layers detect:

- Shapes
- Textures

Deep layers detect:

- Faces
- Objects
- Complex structures

---

# 11. Padding

Padding means adding extra pixels around the image border.

## Why Padding?

Without padding:

- Output shrinks after each convolution
- Information near borders gets lost

## Types of Padding

### Valid Padding

No extra pixels added.

### Same Padding

Output size remains same.

---

# 12. Stride

Stride defines how many pixels the filter moves.

## Stride = 1

Moves one pixel at a time.

## Stride = 2

Moves two pixels.

Larger stride:

- Reduces output size
- Faster computation
- Less detail captured

---

# 13. Pooling Layers

Pooling reduces spatial dimensions.

Benefits:

- Reduces computation
- Reduces overfitting
- Keeps important features

## Types of Pooling

### Max Pooling

Takes maximum value.

Most commonly used.

### Average Pooling

Takes average value.

---

# 14. Activation Functions

Activation functions introduce non-linearity.

Without them, CNN behaves like a linear model.

## ReLU (Rectified Linear Unit)

Most popular.

Formula:

f(x) = max(0, x)

Advantages:

- Fast
- Simple
- Reduces vanishing gradient problem

## Other Activations

- Sigmoid
- Tanh
- Leaky ReLU
- ELU

---

# 15. Fully Connected Layers

After feature extraction:

- Feature maps are flattened
- Passed into dense layers

These layers perform final classification.

Role:

- Learn high-level relationships
- Predict class probabilities

---

# 16. Softmax and Classification

Softmax converts outputs into probabilities.

Example:

| Class | Probability |
|---|---|
| Cat | 0.90 |
| Dog | 0.07 |
| Car | 0.03 |

Highest probability becomes prediction.

---

# 17. Forward Propagation in CNNs

Flow:

1. Input image enters CNN
2. Convolution extracts features
3. Activation applied
4. Pooling reduces dimensions
5. Repeat layers
6. Flattening
7. Dense layers
8. Output prediction

---

# 18. Backpropagation in CNNs

Backpropagation updates weights using errors.

Steps:

1. Calculate prediction error
2. Compute gradients
3. Update filters and weights
4. Reduce loss

This process continues across epochs.

---

# 19. Loss Functions

Loss measures prediction error.

## Common Loss Functions

### Binary Cross Entropy

Used for binary classification.

### Categorical Cross Entropy

Used for multi-class classification.

Lower loss means better performance.

---

# 20. Gradient Descent and Optimizers

Optimizers update weights.

## Gradient Descent

Moves weights toward minimum loss.

## Common Optimizers

| Optimizer | Description |
|---|---|
| SGD | Basic optimizer |
| Adam | Most popular |
| RMSProp | Good for adaptive learning |
| Adagrad | Adaptive learning rate |

Adam is widely used because of faster convergence.

# 22. Popular CNN Architectures

## LeNet

One of the earliest CNNs.

Used for handwritten digit recognition.

## AlexNet

Won ImageNet 2012.

Started deep learning revolution in computer vision.

## VGGNet

Uses very deep architecture with 3×3 filters.

## ResNet

Introduced residual connections.

Solved vanishing gradient problem.

## InceptionNet

Uses parallel convolutions.

## EfficientNet

Balances depth, width, and resolution.

Highly efficient.

---

# 23. Transfer Learning

Transfer learning uses pre-trained CNN models.

Instead of training from scratch:

- Use existing learned weights
- Fine tune on custom dataset

Popular pretrained models:

- ResNet
- VGG16
- MobileNet
- EfficientNet

Advantages:

- Faster training
- Better accuracy
- Requires less data

---

# 24. Data Augmentation

Artificially increases dataset size.

Techniques:

- Rotation
- Flipping
- Zooming
- Cropping
- Brightness adjustment
- Noise addition

Benefits:

- Reduces overfitting
- Improves generalization

---

# 25. Image Preprocessing

Important preprocessing steps:

## Resizing

All images converted to same dimensions.

## Normalization

Pixel values scaled.

Usually between:

- 0 to 1
- -1 to 1

## Noise Removal

Improves image quality.

---

# 26. Overfitting and Underfitting

## Overfitting

Model memorizes training data.

High training accuracy but poor testing accuracy.

## Underfitting

Model fails to learn patterns.

Low performance on both training and testing data.

---

# 27. Regularization Techniques

Methods to prevent overfitting:

## Dropout

Randomly disables neurons.

## Early Stopping

Stops training when validation loss increases.

## L1/L2 Regularization

Adds penalties to weights.

---

# 28. Batch Normalization

Normalizes activations during training.

Benefits:

- Faster training
- Stable learning
- Higher accuracy

Usually placed after convolution and before activation.

---

# 29. Hyperparameters in CNNs

Important hyperparameters:

| Hyperparameter | Meaning |
|---|---|
| Learning Rate | Step size for updates |
| Batch Size | Images processed together |
| Epochs | Full dataset passes |
| Filter Size | Kernel dimensions |
| Number of Filters | Feature extraction power |
| Stride | Filter movement |

Hyperparameter tuning strongly affects performance.

# 30. Evaluation Metrics

## Accuracy

Correct predictions percentage.

## Precision

Correct positive predictions.

## Recall

Ability to find all positives.

## F1 Score

Balance of precision and recall.

## Confusion Matrix

Shows prediction distribution.
