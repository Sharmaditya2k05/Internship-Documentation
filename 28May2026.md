# 1. Introduction to Computer Vision

The ability through which a computer or a machine can interpret information from visual resources like images, videos etc.

Replicating the working of eyes using computers through the concept of AI and ML.

---

# 2. What is Image Classification?

It is the process of identifying the image and providing them a label after a set of pattern identification and processing.

---

# 3. Traditional Machine Learning vs CNNs

## Traditional ML Approach

Traditional methods required manual feature extraction.

Steps:

1. Extract features manually
2. Feed features into ML model
3. Predict output

Problems:

* Time consuming
* Less accurate
* Human dependency
* Poor scalability

## CNN Approach

CNNs automatically learn features from images.

Advantages:

* Automatic feature extraction
* Better accuracy
* Learns complex patterns
* Works well on large datasets

For example: If I want to predict an image of a dog, in a traditional ML model I would have to manually provide features like ear size, eyes, fur texture, etc. But in a CNN model, I would just have to provide an image of a dog and its label; the model would automatically extract the features.

# 4. Basics of Digital Images

An image is represented as a matrix of pixel values.

## Monochrome Image

Uses only shades of one color.

## Grayscale Image

Single channel type of monochrome image that uses all shades of gray ranging from white to black.

## RGB Image

Contains 3 channels:

* Red
* Green
* Blue

# 5. Neural Networks

A neural network is the replication of the neuron system of a human brain using computers.

A Neural Network consists of:

* Input Layer
* Hidden Layers
* Output Layer

Each neuron performs:

1. Weighted sum
2. Activation function
3. Output generation

---

# 6. What is a Convolutional Neural Network (CNN)?

Convolution is a mathematical operation in which a small matrix called a kernel is applied over an input to produce an output by performing element-wise multiplication and summation.

CNN is a deep learning architecture specifically designed for image processing.

CNNs learn:

* Edges
* Shapes
* Textures
* Patterns
* Objects

Automatically.

---

# 7. Core Building Blocks of CNNs

Main components:

1. Convolution Layer
2. Activation Function
3. Pooling Layer
4. Fully Connected Layer
5. Output Layer

---

# 8. Convolution Operation

Convolution is the most important operation in CNN.

A small matrix called a filter slides over the image.

At each position:

1. Element-wise multiplication
2. Summation
3. Output generation

This helps detect patterns.

Example features detected:

* Vertical edges
* Horizontal edges
* Corners
* Curves

---

# 9. Filters / Kernels

A filter is a small matrix such as:

* 3 × 3
* 5 × 5
* 7 × 7

Each filter detects a specific feature.

As training progresses, CNN learns the best filters automatically.

---

# 10. Feature Maps

The output produced after convolution is called a Feature Map.

Feature maps contain important extracted features from the image.

Early layers detect:

* Edges
* Lines

Middle layers detect:

* Shapes
* Textures

Deep layers detect:

* Faces
* Objects
* Complex structures

---

# 11. Padding

Padding means adding extra pixels around the image border.

## Why Padding?

Without padding:

* Output shrinks after each convolution
* Information near borders gets lost

---

# 12. Stride

Stride defines how many pixels the filter moves.

## Stride = 1

Moves one pixel at a time.

## Stride = 2

Moves two pixels.

Larger stride:

* Reduces output size
* Faster computation
* Less detail captured

---

# 13. Pooling Layers

Pooling reduces image size by keeping only important information.

Benefits:

* Reduces computation
* Speeds up training
* Keeps important features

## Types of Pooling

### Max Pooling

Takes maximum value.

### Average Pooling

Takes average value.

---

# 14. Activation Functions

Activation functions introduce non-linearity.
Without them, CNN behaves like a linear model.

* ReLU
* Sigmoid
* Tanh
* Leaky ReLU
* ELU

---

# 15. Fully Connected Layers

After feature extraction:

* Feature maps are flattened
* Passed into dense layers

These layers perform final classification.

---

# 16. Softmax and Classification

Softmax converts outputs into probabilities.
Highest probability becomes prediction.

---

# 17. Forward Propagation in CNNs

Flow:

1. Input image enters CNN
2. Convolution extracts features
3. Activation applied
4. Pooling reduces dimensions
5. Repeat layers
6. Flattening
7. Dense layers
8. Output prediction

---

# 18. Backpropagation in CNNs

Backpropagation updates weights using errors.

Steps:

1. Calculate prediction error
2. Compute gradients
3. Update filters and weights
4. Reduce loss

This process continues across epochs.

---

# 19. Loss Functions

Loss measures prediction error.

---

# 20. Gradient Descent and Optimizers

Optimizers update weights.

## Gradient Descent

Moves weights toward minimum loss.

---

# 24. Overfitting and Underfitting

## Overfitting

Model memorizes training data.

High training accuracy but poor testing accuracy.

## Underfitting

Model fails to learn patterns.

Low performance on both training and testing data.

---

# 25. Regularization Techniques

Methods to prevent overfitting:

## Dropout

Randomly disables neurons.

## Early Stopping

Stops training when validation loss increases.

## L1/L2 Regularization

Adds penalties to weights.

---

# 26. Batch Normalization

Normalizes activations during training.

Benefits:

* Faster training
* Stable learning
* Higher accuracy

Usually placed after convolution and before activation.
