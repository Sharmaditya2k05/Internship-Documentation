# Introduction

Machine learning models often function as black-box systems, making it difficult to understand the reasoning behind their predictions. Counterfactual Explanations are an Explainable Artificial Intelligence (XAI) technique that identifies the minimum changes required in the input features to alter a model's prediction.

During this task, Counterfactual Explanations were implemented on two benchmark datasets:

- Iris Dataset (Multiclass Classification)
- Titanic Dataset (Binary Classification)

This implementation helped understand model behavior, feature sensitivity, and decision boundaries while improving transparency and interpretability.

## Import Libraries

```python
import pandas as pd
import numpy as np
import seaborn as sns
import dice_ml

from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier
from sklearn.preprocessing import LabelEncoder
```

---

# Part 1 : Iris Dataset

```python
iris = load_iris()

df = pd.DataFrame(
    iris.data,
    columns=iris.feature_names
)

df["target"] = iris.target

X = df.drop("target", axis=1)
y = df["target"]

model = RandomForestClassifier(random_state=42)

model.fit(X, y)

data = dice_ml.Data(
    dataframe=df,
    continuous_features=iris.feature_names,
    outcome_name="target"
)

dice_model = dice_ml.Model(
    model=model,
    backend="sklearn"
)

explainer = dice_ml.Dice(
    data,
    dice_model
)

query = df.iloc[[0]]

counterfactual = explainer.generate_counterfactuals(
    query,
    total_CFs=3,
    desired_class="opposite"
)

counterfactual.visualize_as_dataframe()
```

# Part 2 : Titanic Dataset

```python
titanic = sns.load_dataset("titanic")

titanic = titanic[[
    "pclass",
    "sex",
    "age",
    "fare",
    "sibsp",
    "parch",
    "embarked",
    "survived"
]]

titanic = titanic.dropna()

encoder = LabelEncoder()

titanic["sex"] = encoder.fit_transform(
    titanic["sex"]
)

titanic["embarked"] = encoder.fit_transform(
    titanic["embarked"]
)

X = titanic.drop("survived", axis=1)

y = titanic["survived"]

model = RandomForestClassifier(random_state=42)

model.fit(X, y)

data = dice_ml.Data(
    dataframe=titanic,
    continuous_features=[
        "age",
        "fare",
        "sibsp",
        "parch"
    ],
    outcome_name="survived"
)

dice_model = dice_ml.Model(
    model=model,
    backend="sklearn"
)

explainer = dice_ml.Dice(
    data,
    dice_model
)

query = titanic.iloc[[10]]

counterfactual = explainer.generate_counterfactuals(
    query,
    total_CFs=3,
    desired_class="opposite"
)

counterfactual.visualize_as_dataframe()
```
