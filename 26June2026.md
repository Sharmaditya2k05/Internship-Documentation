# Objective

The objective of this task was to generate synthetic datasets for the AI Smart City project to expand the available data while preserving the statistical characteristics of the original datasets. The generated datasets will be used for machine learning model development, testing, simulation, and performance evaluation without compromising sensitive information.

---

# Introduction

Large-scale AI applications require diverse and high-quality datasets for effective model training. However, real-world Smart City datasets may contain sensitive information, missing records, or insufficient samples for machine learning tasks. Synthetic dataset generation provides a practical solution by creating artificial records that closely resemble the original data while protecting privacy.

During this task, synthetic datasets were generated for multiple Smart City domains using statistical sampling techniques after analyzing the distribution of the original data.

# Implementation Steps

### Step 1

Loaded and inspected the original Smart City datasets.

### Step 2

Performed data preprocessing by handling missing values, removing duplicate records, and validating data types.

### Step 3

Separated numerical and categorical features.

### Step 4

Learned statistical properties such as mean, standard deviation, and category frequencies.

### Step 5

Generated synthetic numerical values using statistical sampling techniques.

### Step 6

Generated synthetic categorical values while maintaining the original category distributions.

### Step 7

Combined generated features to create complete synthetic datasets.

### Step 8

Exported the generated datasets for future machine learning experiments.
