# Objective

---

# Introduction

Synthetic data generation is an important technique in machine learning that enables the creation of artificial datasets while preserving the statistical properties of real-world data. Such datasets are useful when real data is limited or contains sensitive information.

During this task, the Titanic dataset was selected because it contains both numerical and categorical features, making it suitable for demonstrating statistical synthetic data generation techniques.

---

The dataset contains passenger information including:

* Passenger Class
* Gender

* Survival Status
