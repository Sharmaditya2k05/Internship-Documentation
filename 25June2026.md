# Objective

The objective of this task was to generate a synthetic version of the Titanic dataset using statistical sampling techniques and validate the generated dataset by comparing it with the original dataset.

---

# Introduction

Following the preprocessing and statistical analysis performed in the previous phase, the synthetic dataset generator was implemented to create artificial passenger records. The generated dataset was evaluated to verify that it preserved the statistical characteristics of the original Titanic dataset while producing new synthetic records suitable for machine learning experiments.

# Implementation Steps

1. Generated synthetic numerical features using normal distributions.
2. Generated synthetic categorical features using category probabilities.
3. Combined all generated features into complete synthetic records.
4. Compared statistical summaries of the original and synthetic datasets.
5. Verified missing values and duplicate records.
6. Exported the generated dataset as a CSV file.

---

# Validation Techniques

The generated synthetic dataset was validated using:

* Mean Comparison
* Standard Deviation Comparison
* Minimum and Maximum Value Analysis
* Category Frequency Comparison
* Missing Value Analysis
* Duplicate Record Detection
* Dataset Shape Comparison
