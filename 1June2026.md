# Introduction

Image classification is one of the most widely used applications of Artificial Intelligence and Computer Vision. Unlike the Fashion-MNIST dataset used in previous tasks, real-world image datasets contain variations in lighting conditions, image sizes, backgrounds, and object positions, making classification more challenging.

To address these challenges, Transfer Learning was used. Instead of training a deep neural network from scratch, a pre-trained MobileNetV2 model was utilized. MobileNetV2 has already learned rich image features from the ImageNet dataset and can be adapted for binary classification tasks such as Cat vs Dog recognition.

Data augmentation techniques were also applied to improve model generalization and reduce overfitting.

# Code Implementation

```python
# TensorFlow Cat vs Dog Classification
# MobileNetV2 Transfer Learning

import tensorflow as tf
import matplotlib.pyplot as plt
import os
from PIL import Image

DATASET_PATH = "PetImages"

IMG_SIZE = (180,180)
BATCH_SIZE = 32

# Data Augmentation
data_augmentation = tf.keras.Sequential([
    tf.keras.layers.RandomFlip("horizontal"),
    tf.keras.layers.RandomRotation(0.1),
    tf.keras.layers.RandomZoom(0.1)
])

# MobileNetV2 Base Model
base_model = tf.keras.applications.MobileNetV2(
    input_shape=(180,180,3),
    include_top=False,
    weights='imagenet'
)

base_model.trainable = False

model = tf.keras.Sequential([
    data_augmentation,
    tf.keras.layers.Rescaling(1./255),
    base_model,
    tf.keras.layers.GlobalAveragePooling2D(),
    tf.keras.layers.Dropout(0.3),
    tf.keras.layers.Dense(1, activation='sigmoid')
])

model.compile(
    optimizer='adam',
    loss='binary_crossentropy',
    metrics=['accuracy']
)
```
