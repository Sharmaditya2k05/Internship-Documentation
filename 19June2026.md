# Introduction

Machine learning models are generally trained in Python environments such as Jupyter Notebook. However, to make these models accessible to web and mobile applications, they need to be deployed as APIs.

Flask is a lightweight Python web framework widely used for deploying machine learning models. It enables applications to receive user input through HTTP requests, process the data using a trained model, and return predictions in JSON format.

During this task, a Flask REST API was developed for the Iris Flower Classification model to understand the complete deployment workflow.

# Code Implementation

## Import Required Libraries

```python
from flask import Flask, request, jsonify
from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier
import numpy as np
```

---

## Load Dataset and Train Model

```python
iris = load_iris()

X = iris.data
y = iris.target

model = RandomForestClassifier(random_state=42)

model.fit(X, y)
```

---

## Create Flask Application

```python
app = Flask(__name__)

class_names = [
    "Setosa",
    "Versicolor",
    "Virginica"
]
```

---

## Home Route

```python
@app.route("/")
def home():

    return jsonify({

        "message": "Iris Prediction API is Running"

    })
```

---

## Prediction Endpoint

```python
@app.route("/predict", methods=["POST"])

def predict():

    data = request.get_json()

    features = np.array([[

        data["sepal_length"],
        data["sepal_width"],
        data["petal_length"],
        data["petal_width"]

    ]])

    prediction = model.predict(features)[0]

    probability = model.predict_proba(features)[0]

    return jsonify({

        "input": data,

        "output": {

            "prediction": class_names[prediction],

            "confidence": round(float(max(probability))*100,2)

        }

    })
```

---

## Run Flask Server

```python
if __name__ == "__main__":

    app.run(debug=True)
```

# Concepts Explored

## Flask Framework

Flask is a lightweight Python framework used to develop web applications and REST APIs.

---

## REST API

A REST API allows different applications to communicate using HTTP requests such as GET, POST, PUT, and DELETE.

---

## JSON

JSON (JavaScript Object Notation) is a lightweight data format used for exchanging information between clients and servers.

---

## Machine Learning Deployment

A trained machine learning model can be integrated into a web application so that predictions are generated in real time through API requests.

---

## HTTP Methods

* GET – Retrieve information
* POST – Send data for prediction
* PUT – Update existing data
* DELETE – Remove existing data
