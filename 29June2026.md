# Introduction

Modern machine learning models often achieve high prediction accuracy but behave as black-box systems, making it difficult to understand their decision-making process. Explainable Artificial Intelligence (XAI) addresses this challenge by providing methods that improve model transparency and interpretability.

Counterfactual explanations are a popular XAI technique that answers the question:

*"What is the smallest change required in the input data to obtain a different prediction?"*

Rather than explaining why a prediction occurred, counterfactuals suggest actionable modifications that could change the model's output.

---

# What are Counterfactual Explanations?

Counterfactual explanations generate alternative versions of an input sample by modifying one or more feature values while keeping other attributes unchanged.

Example:

Current Prediction:

* Loan Status → Rejected

Counterfactual Explanation:

* Increase Annual Income by ₹1,50,000
* Reduce Existing Loan Amount

New Prediction:

* Loan Status → Approved

---

# Importance of Counterfactual Explanations

Counterfactual explanations help to:

* Improve model interpretability.
* Increase transparency in AI systems.
* Build user trust.
* Provide actionable recommendations.
* Support decision-making.
* Identify important influencing features.
* Improve fairness and accountability.
