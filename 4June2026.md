# Introduction

Image classification is one of the fundamental tasks in Computer Vision. Over the years, several deep learning architectures have been developed to improve classification accuracy, reduce computational complexity, and enhance feature extraction capabilities.

During this task, various image classification models were studied and compared to understand their design philosophies, performance characteristics, and suitability for different applications.

---

# Models Explored

## 1. LeNet-5

### Overview

LeNet-5 is one of the earliest Convolutional Neural Networks developed by Yann LeCun for handwritten digit recognition.

### Key Features

- Simple CNN architecture
- Convolution Layers
- Average Pooling Layers
- Fully Connected Layers

### Applications

- Handwritten Digit Recognition
- MNIST Classification

### Advantages

- Easy to understand
- Lightweight architecture
- Fast training

### Limitations

- Low accuracy on complex datasets
- Limited feature extraction capability

---

## 2. AlexNet

### Overview

AlexNet won the ImageNet Challenge in 2012 and revolutionized deep learning-based image classification.

### Key Features

- Deep CNN architecture
- ReLU Activation Function
- Dropout Regularization
- GPU-based training

### Applications

- General Image Classification
- Object Recognition

### Advantages

- Improved feature extraction
- Better accuracy than traditional CNNs

### Limitations

- Large number of parameters
- High computational requirements

---

## 3. VGG16 and VGG19

### Overview

VGG networks use a deep architecture with small 3×3 convolution filters.

### Key Features

- Uniform architecture
- Deep network structure
- Excellent feature extraction

### Applications

- Image Classification
- Feature Extraction
- Transfer Learning

### Advantages

- High accuracy
- Easy architecture design

### Limitations

- Large model size
- High memory consumption

---

## 4. GoogLeNet (Inception Network)

### Overview

GoogLeNet introduced the Inception Module to improve computational efficiency.

### Key Features

- Inception Blocks
- Parallel Convolution Operations
- Reduced Parameters

### Applications

- Large-scale Image Classification
- Object Recognition

### Advantages

- High accuracy
- Lower computational cost

### Limitations

- Complex architecture

---

## 5. ResNet

### Overview

ResNet introduced Residual Connections to solve the vanishing gradient problem.

### Key Features

- Residual Blocks
- Skip Connections
- Deep Architecture

### Applications

- Image Classification
- Medical Imaging
- Object Detection

### Advantages

- Enables very deep networks
- Excellent performance

### Limitations

- Increased architectural complexity

---

## 6. DenseNet

### Overview

DenseNet connects every layer to every other layer in a feed-forward manner.

### Key Features

- Dense Connections
- Feature Reuse
- Efficient Gradient Flow

### Applications

- Medical Image Analysis
- Classification Tasks

### Advantages

- Improved feature propagation
- Reduced vanishing gradient issues

### Limitations

- Increased memory usage

---

## 7. MobileNet

### Overview

MobileNet is a lightweight CNN architecture designed for mobile and embedded devices.

### Key Features

- Depthwise Separable Convolutions
- Low Computational Cost
- Lightweight Architecture

### Applications

- Mobile Applications
- Edge AI Devices
- Real-time Classification

### Advantages

- Fast inference
- Low memory requirements

### Limitations

- Slightly lower accuracy than larger models

---

## 8. MobileNetV2

### Overview

MobileNetV2 improves MobileNet by introducing inverted residual blocks and linear bottlenecks.

### Key Features

- Inverted Residual Blocks
- Linear Bottlenecks
- Efficient Feature Extraction

### Applications

- Transfer Learning
- Mobile Vision Applications

### Advantages

- High accuracy with low computation
- Suitable for deployment

### Limitations

- Less powerful than large-scale architectures

---

## 9. EfficientNet

### Overview

EfficientNet scales network depth, width, and resolution using a compound scaling method.

### Key Features

- Compound Scaling
- Optimized Architecture
- High Accuracy

### Applications

- Advanced Image Classification
- Transfer Learning

### Advantages

- Excellent accuracy
- Computational efficiency

### Limitations

- More complex scaling strategy

---

## 10. Vision Transformer (ViT)

### Overview

Vision Transformer applies Transformer architectures to image classification tasks.

### Key Features

- Self-Attention Mechanism
- Transformer Encoder
- Patch-Based Processing

### Applications

- Large-Scale Image Classification
- Advanced Computer Vision Tasks

### Advantages

- State-of-the-art performance
- Captures long-range dependencies

### Limitations

- Requires large datasets
- Computationally expensive

# Key Observations

- LeNet is suitable for learning CNN fundamentals.
- AlexNet marked the beginning of modern deep learning breakthroughs.
- VGG provides excellent feature extraction but is computationally expensive.
- ResNet solved the vanishing gradient problem using residual connections.
- MobileNet and MobileNetV2 are ideal for mobile and embedded applications.
- EfficientNet achieves a strong balance between accuracy and efficiency.
- Vision Transformers represent the latest trend in image classification research.
