# Objective

---

# Introduction

Flask is a lightweight Python web framework widely used for building web applications and deploying machine learning models. Before integrating AI models into real-world systems, it is important to understand backend development, request handling, routing, and communication between user interfaces and machine learning models.

During this task, I explored Flask fundamentals, REST API architecture, routing, HTML template rendering, and HTTP request handling. A Flask application for Iris Flower Classification was developed to understand model deployment. Additionally, I explored how Flask APIs could be integrated into my personal **AI Smart City** project, enabling machine learning models to provide intelligent predictions and services through a web interface.
