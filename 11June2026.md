# Introduction

Deep learning models often operate as black boxes, making it difficult to understand how predictions are generated. Advanced explainability methods help visualize internal model behavior and identify important image regions or input features influencing decisions.

---

# Techniques Explored

## 1. Saliency Maps

Highlights important image pixels affecting predictions.

### Implementation

```python
score = output.max()

score.backward()

saliency = input_tensor.grad.abs()
```

### Learning Outcome

* Pixel-level importance visualization
* CNN interpretability

## 2. Grad-CAM

Produces heatmaps highlighting important image regions.

### Implementation

```python
cam = GradCAM(
    model=model,
    target_layers=target_layers
)

    input_tensor=input_tensor
)
```

### Learning Outcome

* CNN visualization
* Region-based explanations
