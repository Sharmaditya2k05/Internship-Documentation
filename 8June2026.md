# Introduction

LeNet-5 is one of the earliest and most influential Convolutional Neural Network (CNN) architectures developed by Yann LeCun in 1998. It was specifically designed for handwritten digit recognition and played a significant role in the development of modern computer vision systems.

The MNIST dataset contains grayscale images of handwritten digits ranging from 0 to 9. Each image has a resolution of 28×28 pixels. The dataset serves as a benchmark dataset for learning and evaluating image classification algorithms.

In this task, LeNet was implemented using TensorFlow and trained on the MNIST dataset to classify handwritten digits accurately.

# Code Implementation

## Dataset Loading

```python
import tensorflow as tf

(X_train, y_train), (X_test, y_test) = tf.keras.datasets.mnist.load_data()
```

---

## Data Preprocessing

```python
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0

X_train = X_train.reshape(-1,28,28,1)
X_test = X_test.reshape(-1,28,28,1)
```

---

## LeNet Architecture

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, AveragePooling2D
from tensorflow.keras.layers import Flatten, Dense

model = Sequential([

    Conv2D(
        6,
        kernel_size=(5,5),
        activation='tanh',
        input_shape=(28,28,1)
    ),

    AveragePooling2D(),

    Conv2D(
        16,
        kernel_size=(5,5),
        activation='tanh'
    ),

    AveragePooling2D(),

    Flatten(),

    Dense(
        120,
        activation='tanh'
    ),

    Dense(
        84,
        activation='tanh'
    ),

    Dense(
        10,
        activation='softmax'
    )
])
```

---

## Model Compilation

```python
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)
```

---

## Model Training

```python
history = model.fit(
    X_train,
    y_train,
    epochs=10,
    batch_size=32,
    validation_split=0.1
)
```

---

## Model Evaluation

```python
loss, accuracy = model.evaluate(
    X_test,
    y_test
)

print(
    f"Test Accuracy: {accuracy*100:.2f}%"
)
```

# Working of LeNet

The LeNet architecture performs image classification through the following stages:

### Input Layer

Receives a 28×28 grayscale image.

### Convolution Layer 1

Extracts low-level image features such as edges and corners.

### Average Pooling Layer

Reduces image dimensions while preserving important information.

### Convolution Layer 2

Extracts higher-level patterns and shapes.

### Average Pooling Layer

Further reduces spatial dimensions.

### Fully Connected Layers

Combine extracted features to learn digit-specific representations.

### Output Layer

Generates probabilities for each digit class using Softmax activation.
